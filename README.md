# 🎁 Happy Birthday Shuvro ❤️ (28th September)

A luxury, romantic, and interactive Birthday Surprise web experience created using pure **HTML5, CSS3, and Vanilla JavaScript**.

## ✨ Features
- 🎁 **3D Animated Gift Box Intro**: Realistic unboxing animation with rotating lid and light burst.
- 🎆 **Full-screen Confetti & Fireworks**: Native HTML5 Canvas particle systems.
- 🎵 **Celestial Music Box BGM**: Automated romantic Happy Birthday melody generated using Web Audio API (100% offline & zero dependencies).
- 🎂 **Interactive Cake & Candles**: Blow out candles with rising smoke and hidden wish reveal.
- 📸 **Polaroid Memory Gallery**: Vintage photo frames with optional client-side photo uploader.
- 💌 **Reasons Why I Love You**: 3D interactive flip cards.
- 📜 **Wax-Sealed Love Letter**: Realistic envelope with a clickable wax seal revealing a heartfelt love note.
- 📱 **100% Responsive**: Tailored for all mobile, tablet, and desktop screens.

## 🚀 How to Run Locally
```bash
# Option 1: Using npm
npm run dev

# Option 2: Using Node directly
node server.js

# Option 3: Direct file
Open index.html in any browser
```
